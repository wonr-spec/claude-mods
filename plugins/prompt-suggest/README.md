# prompt-suggest

턴이 끝나면 대화 흐름을 보고 다음에 보낼 만한 프롬프트 후보 3개를 입력창 위에 보여주는 mod입니다.

- **제안 띠**: 후보를 누르면 입력창에 채워지고, 고친 뒤 보내면 됩니다. `닫기`로 숨깁니다.
- **Tab 제안**: 첫 번째 후보는 빈 입력창에 흐린 글씨로도 나타나 Tab으로 바로 받을 수 있습니다.
- **`/suggest`**: 지금 바로 후보 만들기
- **`/suggest on` · `/suggest off`**: 턴마다 자동 제안 켜기/끄기 (세션이 바뀌어도 유지, 기본은 켬)

후보는 세션 자체 대화를 이어 묻는(`$.model.fork`) 방식이라 프롬프트 캐시를 쓰지만, 턴마다 짧은 모델 호출이 한 번씩 더 생깁니다. 비용이 신경 쓰이면 `/suggest off`로 끄고 필요할 때만 `/suggest`를 쓰세요.
